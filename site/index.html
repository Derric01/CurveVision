Label your images.
Let a model start, you finish.

CurveVision is an open-source editor for annotating images and video: boxes, polygons, masks, keypoints and tracks. Point a detector at a job and it fills in what it can as suggestions; you accept, fix or reject them, and export to the format your training code already reads. Install it on your laptop, or run one copy for your whole team.

Download for your computer or, for a team: docker compose up -d

What's in 1.0

No feature here is a roadmap item. Each one ships in the installer, and each one has tests that run on every change.

Drawing

Every tool has a key, so your hand stays on the keyboard and the mouse.

Video

Tracks with keyframes and interpolation between them, on a timeline you can drag. Frames arrive 36 at a time, so stepping through a clip doesn't wait on the network. , and . jump between keyframes.

Models

Run any detector over a whole job: YOLO, SAM or your own model behind a small HTTP contract, or Claude, OpenAI or Gemini with an API key. Everything it finds lands as a dashed suggestion. You can review the least confident ones first, so your time goes where the model was guessing.

Review

Split a task into jobs, assign them, and send work back with a reason. Issues pin to the exact spot on the frame. Score any job against a ground-truth set and get precision, recall and F1 per label, with each disagreement one click from its frame.

Teams

Organizations with six roles. Single sign-on through OpenID Connect or SAML. Signed webhooks. A REST API with Python and TypeScript clients and a command-line tool.

Your data

The desktop app annotates a folder where it already is, without copying it. Images leave your machine only if you send them somewhere yourself: to a team server, or to a hosted model you add. The app has no analytics and no telemetry. The server runs on your hardware, with Docker or Kubernetes, and stores media in any S3-compatible bucket you choose.

Ninety seconds, start to export

Recorded straight off the screen, nothing staged. YOLO11n labels four photos on a laptop CPU, a person reviews what it found and draws what it missed, then a COCO file comes out. The recording script checks that file holds exactly what you see drawn.

Not in 1.0

Better you hear it here than find out halfway through a project.

  • 3D point clouds. 2D only, including the projected cuboid.
  • Video playback. You step through frames; there's no play button yet.
  • Per-object controls in the editor for relabelling, occlusion and z-order. The data model has them; the buttons don't exist yet.
  • Azure Blob and Google Cloud Storage. S3-compatible storage only.
  • A publisher signature on the installers. Windows and macOS ask you to confirm the first time you open the app. Every file is still checksummed and signed with Sigstore.
  • A bundled model. Bring your own, or use a hosted one with an API key.

For a team

# a server with a certificate from Let's Encrypt, on your own domain
git clone https://github.com/Derric01/CurveVision.git && cd CurveVision
cp .env.example .env            # set CURVEVISION_SECRET_KEY
CURVEVISION_DOMAIN=cv.example.com \
  docker compose -f docker-compose.yml -f deploy/compose.https.yml up -d

Kubernetes: a Helm chart is in deploy/helm, with the operations guide beside it.

Check what you downloaded

cosign verify-blob SHA256SUMS --bundle SHA256SUMS.sigstore.json \
  --certificate-identity-regexp 'https://github.com/Derric01/CurveVision/.github/workflows/release.yml@.*' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
sha256sum --check --ignore-missing SHA256SUMS
