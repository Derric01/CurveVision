Features

Everything a labelling team needs.
Nothing it has to pay for.

The workflow mature annotation platforms are known for, rebuilt to be fast, private and simple to run, from one person's laptop to a whole team.

Model-assisted labelling

Run any detector over a whole job: YOLO, SAM, your own model server, or a hosted model by API key. Its boxes arrive as suggestions, never as finished work. Accept, reject, or review the least confident first. Click an object and an interactive model outlines it.

Every shape

Boxes, rotated boxes, polygons, polylines, points, ellipses, cuboids, skeletons, brush masks and whole-frame tags.

Video and tracks

Track objects across frames with keyframes and interpolation, on a timeline you can drag. Frames load in chunks, so scrubbing stays instant.

Review and quality

Assign, submit, accept or send back. Pin issues to the exact spot, and score jobs against a ground truth with precision, recall and F1.

Private by design

The desktop app annotates folders where they already are, offline. A team server runs on your infrastructure with SSO, roles and signed webhooks.

Exports you can trust

Fifteen formats, each checked in CI by the tool that reads it: pycocotools, Ultralytics, labelme, cityscapesScripts, Datumaro, TensorFlow. Freeze a dataset version with a content hash, and download exactly that version again a year later.

How it works

From raw photos to a training set, in one sitting.

  1. Add your images or videoDrop in files, or point the desktop app at a folder. Nothing is copied.
  2. Let a model take the first passOne click runs a detector over every frame. Everything it finds waits for review.
  3. Review, fix and fill the gapsAccept what's right, reject what isn't, draw what it missed. Keyboard-first.
  4. Export and trainCOCO, YOLO, VOC and more, or a frozen dataset version your experiment can cite.
Desktop & server

Start alone. Grow into a team.

The same editor, the same formats and the same code, as an app you install or a server your whole team opens in a browser. Neither is the lesser.

For one person

The desktop app

  • Install and start drawing. No account, no server
  • Annotates folders in place, fully offline
  • Updates itself, signed and verified
  • Connects to your team's server when you're ready
For a team

The team server

  • Docker image or Helm chart, on your infrastructure
  • Organizations, six roles, job assignment and review
  • Single sign-on with OpenID Connect or SAML
  • REST API, Python and TypeScript SDKs, CLI, webhooks

Your data is the most valuable thing you own. An annotation tool should never be the reason it leaves the building.
