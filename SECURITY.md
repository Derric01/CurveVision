# Security Policy

**Do not report security vulnerabilities through public issues.**

Use [GitHub's private vulnerability reporting](https://github.com/Derric01/CurveVision/security/advisories/new),
or contact a maintainer directly for a private channel.

The full policy — what is in scope, how CurveVision is built to be secure, operator
responsibilities, and a candid list of known limitations — is in
[docs/SECURITY.md](docs/SECURITY.md).
