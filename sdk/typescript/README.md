# @curvevision/client

A typed client for the [CurveVision](https://github.com/Derric01/CurveVision) annotation
platform's REST API. Every path, parameter, request body and response is typed from the
server's own OpenAPI document, so a request the server would refuse is usually a compile
error first.

```bash
npm install @curvevision/client
```

```ts
import { createClient, CurveVisionError, type Schema } from '@curvevision/client';

const cv = createClient({
  baseUrl: 'https://cv.example.com',
  token: process.env.CURVEVISION_TOKEN, // an API token, made on the Workspace page
});

const [workspace] = await cv.call(cv.api.GET('/api/v1/organizations'));

const project: Schema<'ProjectOut'> = await cv.call(
  cv.api.POST('/api/v1/projects', {
    body: {
      organization_id: workspace.id,
      slug: 'street',
      name: 'Street scenes',
      labels: [{ name: 'car' }, { name: 'pedestrian' }],
    },
  }),
);

try {
  await cv.call(cv.api.GET('/api/v1/projects/{project_id}', {
    params: { path: { project_id: 'not-there' } },
  }));
} catch (error) {
  if (error instanceof CurveVisionError) console.log(error.status, error.problem.detail);
}
```

* `cv.api` is an [`openapi-fetch`](https://openapi-ts.dev/openapi-fetch/) client: `GET`,
  `POST`, `PATCH`, `PUT`, `DELETE`, each resolving to `{ data, error, response }`.
* `cv.call(request)` unwraps one: the data, or a thrown `CurveVisionError` carrying the
  server's [problem document](https://www.rfc-editor.org/rfc/rfc9457).
* `token` may be a function, asked on every request — for a session token you refresh.
* `Schema<'Name'>` is any schema the API declares, by name.

The full API, with every endpoint, is at `/api/docs` on any CurveVision server.

## Versions

The package's version follows the server's. Its types are generated by
`scripts/api_types.py` in the CurveVision repository and checked against the server on
every CI run; `npm test` runs against a real server when `CURVEVISION_TEST_SERVER_URL` and
`CURVEVISION_TEST_TOKEN` are set (`python scripts/with_server.py -- npm test` does that).
